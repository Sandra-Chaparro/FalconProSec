# Contributing to FalconProSec

FalconProSec is a personal, independent site. Content is not open for outside
submissions as pull requests, but feedback is very welcome.

- **Corrections:** if something in an investigation or article is wrong or
  missing context, use the contact page and choose “Correction”:
  https://falconprosec.com/contact?reason=correction
- **Investigation ideas:** https://falconprosec.com/contact?reason=investigation
- **Site bugs** (broken links, layout or accessibility issues): open an issue
  in this repository or use the contact page.

For local development setup, see the [README](../README.md).
